# Example practice set

`percent-applications/` is a practice set built by `proofset build m81313` from *Solve General
Applications of Percent*, section 6.2 of [Prealgebra 2e](https://openstax.org/details/books/prealgebra-2e)
by OpenStax.

- `m81313.json`: the problems, answer keys, hints, worked solutions, the result of every code
  check, and the German translations
- `m81313-en.html`, `m81313-de.html`: printable worksheets; open in a browser and print

The problems are new questions written from that chapter, so like the book they are licensed
[CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/). The code in this
repository is MIT licensed.
